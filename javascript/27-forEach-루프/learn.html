배열 순회의 정석: forEach() 메서드

모든 배열 객체는 forEach()라는 강력한 도구를 가지고 있습니다. 이 메서드를 사용하면 복잡한 인덱스 계산 없이도 호텔의 모든 방을 우아하게 방문할 수 있습니다.

1. 콜백 함수와 매개변수

forEach() 메서드에 할일을 적은 '레시피(콜백 함수)'를 전달하면, 자바스크립트는 세 가지 정보를 요리 재료로 제공합니다.

array.forEach((item, index, array) => { /* 실행 코드 */ })
item
현재 방문한 방에 있는 손님(항목)입니다.
index
현재 방문 중인 방 번호(인덱스)입니다.
array
순회 중인 장부(배열) 그 자체입니다.

지배인 메모: 번호(index)나 전체 장부(array)가 필요 없다면 손님(item) 이름만 적어서 간결하게 사용할 수 있습니다.

2. 다양한 순회 방법의 공존

장부를 확인하는 방법은 여러 가지가 있으며, 상황에 맞는 도구를 선택하는 것이 중요합니다.

배열 순회 방법별 특징 비교
방법 장점 단점
for 문 유연하고 세밀한 제어 가능 코드가 길어 가독성이 떨어짐
for...of 문 간결하고 직관적임 인덱스를 다루기 어려움
forEach 메서드 문법이 간단하고 가독성 좋음 break, continue 사용 불가

3. 실무 활용 예시

과일 바구니에 담긴 모든 과일을 하나씩 꺼내어 인사하는 가장 현대적인 방법입니다.

fruitBasket.forEach((fruit) => {
  console.log('과일 바구니 안의 과일에는 "' + fruit + '"이 포함되어 있습니다.')
})

🚀 학습 요약

  • 함수형 스타일의 반복 작업이 필요할 때는 forEach를 사용하세요.
  • 중간에 멈춰야(break) 한다면 for나 for...of가 정답입니다.
  • 인덱스 번호가 굳이 필요 없다면 for...of가 가장 읽기 쉽습니다.
